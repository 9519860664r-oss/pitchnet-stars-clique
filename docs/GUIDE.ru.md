# Быстрый старт

[English](GUIDE.md) · **Русский** · Полное руководство: [PDF (RU)](PitchNet-StarsClique-Manual-RU.pdf), [PDF (EN)](PitchNet-StarsClique-Manual-EN.pdf)

## 1. Установка

1. Скачайте **PitchNet-StarsClique-1.0.0-Setup.exe** со страницы [Releases](https://github.com/9519860664r-oss/pitchnet-stars-clique/releases/latest).
2. Закройте DAW, запустите установщик, оставьте отмеченным компонент VST3.
3. Пересканируйте плагины. Плагин называется **PitchNet (Stars Clique ver)** (производителем в списке указан Session Loops).

| Что | Куда |
|---|---|
| VST3-плагин | `C:\Program Files\Common Files\VST3\Stars Clique\` |
| Отдельная программа | `C:\Program Files\Stars Clique\PitchNet\` |
| Нейросетевые модели | `C:\ProgramData\Session Loops\PitchNet\models\` |
| Настройки, скин, свои строи | `%APPDATA%\PitchNet\` |

## 2. Как загрузить звук

**FL Studio и другие программы без ARA**

1. Поставьте PitchNet в канал микшера каждого вокала, до реверба и дилея.
2. Откройте любое окно PitchNet. В списке дорожек видны все экземпляры.
3. Нажмите розовое кольцо **Transfer** у каждой дорожки, которую нужно записать.
4. Запустите песню. Пауза или стоп — дубли завершаются и анализируются.

Если снова запустить с любого места, перепишется только этот участок. Переход в начало петли тоже завершает дубль.

**REAPER (ARA)**: добавьте PitchNet как эффект на айтем или дорожку. Звук доступен сразу. Для групп из нескольких дорожек REAPER даёт PitchNet прочитать другие дорожки только после воспроизведения: если в окне написано *Press Play once*, ненадолго запустите песню.

## 3. Правка

| Действие | Результат |
|---|---|
| Тянуть ноту вверх-вниз или вбок | Высота или время (первое движение фиксирует ось) |
| Двойной клик по ноте | Встать точно в ноту тональности |
| Alt + протяжка | Двигать без сетки |
| Ввод в Note Inspector | Высота (`C3`, `+2`, `-30 ct`), вибрато, дрейф, форманты, громкость |
| Голубой овал **Edit** | Править и эту дорожку (сколько угодно сразу) |
| Белый овал **Ghost** | Показать дорожку серыми нотами для ориентира |
| Правый клик в редакторе | Quantize Time, Align to Reference, Leveling, Sibilants (показ, границы, снять, баланс), Restore Original, выделение |
| Group selected, затем **Unison** / **Timing** | Даблы следуют за высотой / таймингом лида (ползунки силы) |
| Правый клик по линейке времени | Смена тональности, участки замены |
| Кнопка тональности | Тональность, свои строи с центами, A4 400–480 Гц |

## 4. Навигация

| Ввод | Результат |
|---|---|
| Колесо / Shift + колесо | Прокрутка по вертикали / горизонтали |
| Ctrl + Alt + колесо, щипок | Масштаб по обеим осям |
| Ctrl + Shift + протяжка | Рука |
| Ctrl + Alt + протяжка | Лупа |
| Протяжка по линейке вверх-вниз | Масштаб по времени |
| Двойной клик по полосе прокрутки | Показать всё |

## 5. Горячие клавиши

`1` `2` `3` `4` инструменты · `Space` воспроизведение/пауза · `Esc` стоп · `Ctrl+Z` / `Ctrl+Y` отмена/повтор · `Ctrl+A` выделить всё · `Ctrl+C` / `Ctrl+X` / `Ctrl+V` копировать/вырезать/вставить ноты · `Up` / `Down` полутон · `Shift+Up` / `Shift+Down` октава · `Delete` заглушить ноты
